# Andi-mawadda-taiba---105841103623--TUGAS-BESAR-APPLIED-MACHINE-LEARNING

Repositori ini berisi seluruh hasil pengerjaan Tugas Besar mata kuliah Applied Machine Learning oleh Andi Mawadda Taiba (105841103623) dari kelas 5AI-A. Proyek ini mengangkat studi kasus Prediksi Hujan menggunakan dataset cuaca Open-Meteo untuk wilayah Makassar selama tahun 2025. Dataset cuaca yang digunakan terdiri dari fitur-fitur penting seperti suhu udara, kelembapan relatif, curah hujan, kecepatan angin, dan tingkat tutupan awan. Seluruh proses analisis dilakukan mengikuti alur CRISP-DM, mulai dari memahami permasalahan, eksplorasi dataset, pembersihan dan rekayasa fitur, hingga pemodelan dan deployment.

Dalam tahap pemodelan, lima algoritma Machine Learning diuji dan dibandingkan, yaitu K-Nearest Neighbors (KNN), Gaussian Naive Bayes, Logistic Regression, Decision Tree, dan Random Forest. Setiap model dilatih menggunakan data cuaca jam-an dan dievaluasi menggunakan metrik akurasi serta AUC. Berdasarkan hasil pengujian, Gaussian Naive Bayes menjadi model terbaik karena memberikan performa sempurna dengan nilai Accuracy = 1.000 dan AUC = 1.000, serta menunjukkan stabilitas yang sangat baik. Model terbaik tersebut kemudian disimpan ke dalam file .pkl dan digunakan pada tahap deployment.

Tahap akhir dari proyek ini adalah pembangunan antarmuka prediksi berbasis web menggunakan Gradio. Aplikasi ini memungkinkan pengguna memasukkan nilai fitur cuaca secara manual dan langsung mendapatkan prediksi apakah kondisi tersebut berpotensi terjadi hujan atau tidak, lengkap dengan probabilitasnya. Dengan implementasi ini, model yang dibangun dapat diuji secara interaktif dan memberikan gambaran nyata tentang bagaimana Machine Learning dapat dimanfaatkan dalam konteks prediksi cuaca sehari-hari.

Repositori ini juga menyertakan seluruh dokumen pendukung seperti dataset, file notebook (.ipynb) untuk preprocessing, modeling, dan deployment, serta LK Perancangan Proyek dan Laporan Tugas Besar. Dengan demikian, repositori ini tidak hanya berfungsi sebagai tempat penyimpanan kode, tetapi juga sebagai dokumentasi lengkap perjalanan pengerjaan proyek dari awal hingga akhir.
